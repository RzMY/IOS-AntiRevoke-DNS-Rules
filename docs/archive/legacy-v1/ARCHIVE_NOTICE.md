# Legacy v1 documentation

This directory contains the documentation for the retired v1 pipeline, which extracted domains directly from upstream mobileconfig `SupplementalMatchDomains` values.

That upstream data path is permanently obsolete because the source rules moved behind DNS services. These files are retained only for historical context and must not be used as current setup or architecture guidance.
